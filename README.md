# Dia Nacional do Surdo — IFRR

Landing page desenvolvida para registrar e divulgar a ação em comemoração ao **Dia Nacional do Surdo**, realizada em 26 de setembro no Instituto Federal de Roraima (IFRR).

O projeto busca valorizar a comunidade surda, destacar a importância da Língua Brasileira de Sinais (Libras) e apresentar os registros fotográficos e depoimentos em vídeo do evento por meio de uma experiência digital visual, responsiva e acessível.

## Objetivos

- Divulgar os registros da ação realizada no IFRR.
- Valorizar a comunidade e a cultura surda.
- Apresentar depoimentos em vídeo dos participantes.
- Facilitar a visualização das fotografias e dos vídeos.
- Aplicar princípios de acessibilidade e responsividade no desenvolvimento web.

## Funcionalidades

- **Banner rotativo:** apresentação de fotografias do evento.
- **Galeria interativa:** ampliação das fotografias em uma janela Lightbox.
- **Navegação entre imagens:** controles para avançar e voltar, além de navegação por teclado e gestos em dispositivos móveis.
- **Depoimentos em vídeo:** reprodução dos relatos dos participantes.
- **Visualizador de vídeos:** ampliação dos depoimentos em uma janela própria, com controles de reprodução e navegação.
- **Recursos de acessibilidade:** ajuste do tamanho do texto e opção de alto contraste.
- **Design responsivo:** adaptação para computadores, tablets e celulares.
- **Identidade institucional:** espaço destinado à logo do IFRR.

## Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** identidade visual, layouts, animações e responsividade.
- **JavaScript:** banner rotativo, controles da galeria, Lightbox e recursos interativos.

## Como executar localmente

1. Clone o repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. Inicie um servidor HTTP local:

   ```bash
   python3 -m http.server 8080
   ```

4. Abra o endereço no navegador:

   `http://localhost:8080`

Não é necessário instalar bibliotecas adicionais para executar a versão estática da página.

## Acessibilidade

O projeto considera recursos como contraste visual, textos alternativos para imagens, controles identificados e navegação por teclado.

Como melhoria contínua, recomenda-se incluir legendas em português e tradução em Libras nos vídeos, além de testar a navegação com usuários surdos e pessoas com diferentes necessidades de acessibilidade.

## Publicação

O projeto pode ser publicado gratuitamente pelo **GitHub Pages**, utilizando a branch principal do repositório e a pasta raiz como fonte de publicação.

Após a configuração, o GitHub fornecerá o endereço público do site.
